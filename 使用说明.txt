GTA5 DMA Control Console
=======================

【运行要求】
- Windows 10/11 x64 控制主机 + DMA / FPGA 设备（MemProcFS + LeechCore）
- 目标主机 GTA5 或 GTA5 Enhanced（程序自动识别）

【使用】
1. 本包内所有文件放同一目录；目标机启动游戏后运行 GTA5_DMA.exe
2. 热键：Insert 显隐 | F5 传送标记点 | F6 传送任务点 | End 退出
3. 左侧导航切换功能页；面板可拖动、右下角手柄缩放（几何与外观记到 %LOCALAPPDATA%\GTA5_DMA\window.ini）
4. 底部状态栏常显 PID / 基址 / 人物模型 / 构建标记，操作前先看一眼构建标记

【功能概览】
- 战局玩家：加密 Ped 池解析 → 名称 / RID / 等级 / 金钱 / KD / 血量 / 护甲 / 距离 / 载具 / 无敌，
  支持搜索、传送、击杀
- 战局载具：50 米内实时扫描，车名 / 血量 / 距离，一键「传送到它」（玩家 → 载具旁，错开 2 米防卡模）
- 人物控制：无敌 / 护甲锁定 / 永不通缉 / 隐身 / 无碰撞 / 速度与布娃娃控制
- 载具编辑：属性、附加能力、操控数据；载具修复（当前载具 / 一键修复 50 米内战局载具，逐字段读回校验）
- 武器：属性读取、无限弹药、无需装弹
- 位置传送：F5 标记点 / F6 任务点 / 坐标编辑（三列瀑布流，相邻点位按坐标自动合并）
- 进度与解锁：RP 经验倍率、改外貌免费与免冷却、抢劫与经济价值（佩里克岛主目标价值 / 跳伞挑战奖励，
  「原值 × 倍率」写入，关闭即还原原值）
- 经济与自动化：7 个产业保险箱一键领取（可周期自动）、静音来电、GTA+ 解锁、脚本线程自检（只读）
- 动态偏移解析：特征码扫描 + 每次启动重解析，游戏更新无需改代码

【游戏更新后不必重编译】
- 特征码：每条偏移内置多个备选特征码依次尝试；内置全部失配时，可在 exe 同目录的
  GTA5_DMA_patterns.txt 追加一行：
    偏移名 = 48 8B 0D ? ? ? ? | disp=3 insn=7
  （disp / insn 是该指令的 rel32 位移与指令长度，格式见文件内注释；改文本即时生效）
- 脚本 tunable 索引：名字的 joaat 哈希稳定、索引会漂 —— 每次启动重新解析，优先级为
  ① GTA5_DMA_tunables.txt 手填「名字 = 索引」→ ② tunables.bin（可用 bin = <路径> 指定）
  → ③ 值序列自发现（一组已知值在块内连续且唯一出现即反推位置）→ ④ 内置兜底表
- 诊断：每次启动自动写 GTA5_DMA_diag.txt（已解析偏移 / 每条 tunable 的定位方式与实读值 /
  脚本全局动作格 / 脚本线程清单 / tunable 块可读范围）；也可 `GTA5_DMA.exe --diag [路径]`
  或界面「导出诊断」按钮随时导出
- 写入安全：所有写入都过「合法值区间 / 默认值体检 + 写前比对原值 + 写完读回校验」，
  体检不通过即判「未定位」并跳过（界面上显示为不可用），不会把值写到错误地址

【依赖】
- MemProcFS vmm.dll / LeechCore leechcore.dll（随包分发）
